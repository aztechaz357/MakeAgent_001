# IEC 62443-4-2 要件マップ (独自要約)

> 規格本文の転載ではなく、ID と短い独自要約。SL の割当を含め **規格原本との照合が未完了** (issue #4)。判断を左右する場合は原本で確認する。

読み方: `ID 要約 [基本要件が必要になる最小 SL]`、`RE(n)→SLx` はその強化要件が必要になる最小 SL。目標 SL 以下のものをすべて満たす。
種別: CR は全コンポーネント共通。EDR は組込み機器 (インバータ、サーボ、PLC はこれ)、NDR はネットワーク機器、HDR はホスト機器、SAR はソフトウェアアプリ。
